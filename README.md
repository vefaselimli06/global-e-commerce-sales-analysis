# global-e-commerce-sales-analysis
Global e-commerce sales analysis project using SQL, Excel, and Power BI to explore customer behavior, sales trends, and key performance indicators through interactive dashboards and reporting.
## Project Overview
This project focuses on analyzing global e-commerce sales data to gain insights into customer behavior, sales performance, and market trends.

The goal is to transform raw data into meaningful business insights using SQL for data extraction, Excel for data cleaning and reporting, and Power BI for interactive dashboards and KPI visualization.

## Objectives
- Analyze customer purchasing behavior and segmentation  
- Identify sales trends across products, regions, and time periods  
- Track key performance indicators (KPIs) such as revenue, order volume, and average order value  
- Build interactive dashboards for business decision-making  
- Generate actionable insights for improving sales performance  

## Tools & Technologies
- **SQL** – Data extraction, querying, and transformation  
- **Microsoft Excel** – Data cleaning, Pivot Tables, and reporting  
- **Power BI** – Dashboard creation and data visualization
